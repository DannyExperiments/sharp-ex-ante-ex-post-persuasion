# The four-state persuasion gap

Extract the ZIP and open index.html in a browser. The explorer works offline. Use **Rotate** or drag the tetrahedron. Select **Ex ante** to show full revelation and **Ex post** to show the only posterior allowed by the caps and the fixed mean. Change the Jensen factor M to compare exact tree values.

The worked example has three convex coordinate caps, a uniform prior and four states. At M = 3, the ex-ante optimum is 1 and the ex-post optimum is 7/54. The resulting gap is 54/7.
